How to turn AI on/off in VSCode
--------------------------------------------

#. 
    Open Visual Studio Code

#. 

    press :kbd:`ctrl` + :kbd:`,` on windows and :kbd:`Command` + :kbd:`,` on MacOS to open settings in Visual Studio Code

#. 
    Search for "Disable AI Features" and check or uncheck the box

    .. image:: /images/install/checkboxvscodeai.jpg
        :width: 400
        :align: center

If AI is enabled, you should have an option to sign in in the top right corner, and a copilot icon in the bottom right corner

.. image:: /images/install/AIfeatures.jpg
    :width: 400
    :align: center
